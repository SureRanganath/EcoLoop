About EcoLoop

A Circular Economy Marketplace for Industrial Waste Exchange

What is EcoLoop?

EcoLoop is a web-based industrial waste exchange marketplace that connects industries producing reusable waste materials with industries that can use those materials as raw inputs. The platform promotes a circular economy by keeping materials in productive use rather than sending them to landfill.

For example: a plastic manufacturing company with 500 kg of reusable plastic scraps can list those materials on EcoLoop. A recycling company needing recycled plastic can find that listing, receive an AI-powered recommendation, and submit a purchase request — all within the platform.

The Circular Economy

A circular economy is an economic system aimed at eliminating waste and the continual use of resources. It contrasts with the traditional linear economy (make → use → dispose) by keeping products and materials in use for as long as possible.

Reduce

Minimise industrial waste generation at the source.

Reuse

Find new applications for materials before recycling.

Recycle

Process materials into new products when reuse is not possible.

AI Recommendation System

EcoLoop uses a content-based recommendation engine built with Python and scikit-learn. The system combines:

  • TF-IDF text similarity — matches material descriptions using term frequency–inverse document frequency and cosine similarity.
  • Category compatibility — prioritises exact category matches.
  • Quantity scoring — checks whether available quantity meets the buyer's requirement.
  • Price scoring — evaluates whether the listing price fits the buyer's budget.
  • Location scoring — gives preference to listings in the buyer's preferred state.

Note: This is a content-based approach suitable for small datasets. No pretrained model accuracy is claimed. The system explains each recommendation transparently.
